# IBM Plex Sans

ShareR bundles the unmodified regular and semibold IBM Plex Sans fonts under the
SIL Open Font License 1.1 in [OFL.txt](OFL.txt). Bundling keeps native text metrics
consistent across machines without contacting a font service.

Source: [IBM/plex](https://github.com/IBM/plex/tree/71f558992315a12ca1f06a2215d57962a1992162/packages/plex-sans/fonts/complete/ttf),
